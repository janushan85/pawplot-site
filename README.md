| 주소 | 쓰임 |
|---|---|
| [`/`](https://pawplot.app/) | 홈 — 앱 소개 |
| [`/support.html`](https://pawplot.app/support.html) | **App Store 필수** — 지원(Support) URL |
| [`/privacy.html`](https://pawplot.app/privacy.html) | **App Store·Play 필수** — 개인정보 처리방침 |

## 이 저장소를 직접 고치지 마세요

다시 만듭니다. 여기서 고친 내용은 다음 생성 때 사라집니다.
